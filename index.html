One-time backend setup (about 2 minutes)
  1. Open your Google Sheet → Extensions → Apps Script.
  2. Delete any code there, paste the KAKU backend code below, and save.
  3. In the editor select kwtProvision and click Run. Approve the permissions, then View → Logs and copy the secret it created.
  4. Deploy → New deployment → Web app. Execute as: Me. Who has access: Anyone. Deploy.
  5. Paste the Web app URL and your secret above, then Test connection.

Security note: "Execute as Me + Anyone" means anyone holding both the web app URL and your secret can write to your sheet. The URL alone can do nothing until you run kwtProvision once, and only you (the sheet owner) can run it. Keep the secret private; rotate it any time with kwtRotateSecret.
